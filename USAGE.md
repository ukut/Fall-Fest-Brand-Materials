# Qiskit Fall Fest 2026 — Brand & Graphics Usage

These assets (logos, banners, color palettes, templates, and other graphics) were shared with the QNigeria team for **one purpose only**: building the QNigeria Fall Fest 2026 website (hub-and-spoke site connecting OAU, University of Ibadan, and University of Uyo).

## ✅ You may
- Use these files to build and style the official Fall Fest 2026 website
- Resize or crop images where needed for layout (without distorting logos)
- Reference the approved color palette and typography for consistency across the site

## 🚫 You may not
- Alter, recolor, or redesign the official Qiskit/Fall Fest logos
- Repost or share these files outside this project (personal socials, other events, other repos)
- Use these assets for anything other than the QNigeria Fall Fest 2026 site
- Claim these materials as your own design work

## 📁 Where things live
- All approved assets are in this repo/folder — please don't pull graphics from other sources without checking with [Your Name] first
- If you need a file in a different format or size, ask rather than editing the original

## 🔒 Access
- Access to this folder is granted per-contributor for the duration of the Fall Fest website build
- Access will be reviewed/removed once the site is live

## Questions
